Safee & Tuba — Premium Cinematic Wedding Invitation

Background music:
- Backgroundmusic.mp3 is bundled locally in assets/.
- The site attempts audible autoplay immediately on page load.
- If the browser blocks audible autoplay (common on iPhone/iPad and some Android/desktop configurations), the site starts the music on the first genuine user interaction: tap, click, or key press.
- The lantern interaction also unlocks the audio, so the music starts before/reliably during the invitation-opening sequence.
- Music loops and can be muted with the MUSIC ON/OFF control.

Important browser limitation:
No website can guarantee audible sound merely from opening a URL on every browser/device. iOS Safari, Android browsers, and some desktop browsers can block audible autoplay until the visitor interacts with the page. This build uses the strongest cross-device approach possible without requiring a separate "Tap to enter" screen.
